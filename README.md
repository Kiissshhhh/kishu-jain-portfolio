# Kishu Jain — Digital Resume

A responsive single-page portfolio/resume built with HTML, CSS and vanilla JavaScript. No build step or package installation required.

## Preview locally

1. Download and extract the project folder.
2. Open `index.html` in a browser (or use VS Code Live Server).

## Download a PDF résumé

Open the website and click **Download résumé**. In the print dialog, choose **Save as PDF**. For best results, enable background graphics and use A4 paper. You can also use Ctrl+P / Cmd+P.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `kishu-jain-portfolio`.
2. Upload the contents of this folder (make sure `index.html` is at the repository root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages deployment and open the URL shown in Settings → Pages.

The site is static, so GitHub Pages can host it directly.
